# How to run

dependecies needed:
```
qt6-base
qt6-multimedia
qt6-declarative
```

## 1. Clone the repo
    ```
    git clone https://github.com/<your-username>/cosby.git
    cd cosby
    ```

## 2. Configure the project
    ```
    cmake -B build
    ```

## 3. Build
    ```
        cmake --build build
    ```

## 4. Run
    ```
    ./build/cosby
    ```
